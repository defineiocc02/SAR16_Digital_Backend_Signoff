# 远程 16 位 SAR 与 JSSC 2025：模拟复现、数字衔接及引脚规范

日期：2026-10-02。对标 Huang 等，JSSC 60(3), 813–825，DOI [10.1109/JSSC.2025.3526595](https://doi.org/10.1109/JSSC.2025.3526595)。本轮使用论文全文、36 个当前 OA schematic 的隔离只读提取、远程文本模型、保存的网表及仿真日志。

**20 路非二进制冗余物理权重经校准、加权重构输出 16 位，是论文的正确架构。20 与 16 的位数差异不是复现缺口。** 本文检查电容网络、权重索引、控制阶段、极性、残差尺度和验证证据，不把冗余码当二进制整数，也不以截断 raw code 代替重构。

## 结论和完成程度

远程已经有分体采样、四段 CDAC、AZ、两级前置放大、比较锁存器、Flash 行为模型和晶体管 SAR 时序电路。当前处于**原理图及混合模型已搭建、整机转换链尚未验收**的阶段；模块存在不等于噪声、线性度、速度或功耗达标，无法据此给出“复现完成百分比”或距离论文还差多少 dB。

数字方面有两套不同阶段的实现：远程 `Digital_Process` / `sar_reconstruction` 文本模型，以及本仓库 v5.1 校准 + SRM 辅助核心。保存的模拟顶层和当前 OA 都没有把这些数字模块接成最终 16 位输出链。本仓库的历史后端结果因此不能代表远程完整 ADC。

完成论文复现首先需要闭合四件事：修正重复的整套逻辑实例、锁存器时钟接口并核对采样网络负载；让混合网表能够运行；建立校准、固定 CDAC 残差的 22 次判决及完整重构；在同一条件下验证噪声、INL/DNL、SNDR、吞吐及功耗。现有材料尚不能确认达到或超过论文。

## 确定的结构与流程阻碍

### 完整 SAR 逻辑的 21 份并联复制

当前顶层实例 **`I689<20:0>`** 的 master 是完整 `SAR_Logic_transistor_woflash`，不是单 bit 单元。它的 `BITP<20:0>`、`BITN<20:0>`、`SET<0:20>`、`Dflash<1:0>`、时钟、比较器和电源端口均通过 `<*21>` 重复接到同一组信号。历史网表也实际展开出 21 份完整逻辑并联。

这与模块内部的非二进制冗余位无关。按保存网表的层级语句清点，单份 SAR 逻辑有 1030 个 MOS 模型实例，21 份贡献 21630 个；全顶层递归清点为 26610 个。它们是设计语句库存，不是后仿有效面积或功耗。重复的状态机、输出驱动和输入负载需要修正并重新验证；建议在独立修复副本中将整模块数组改为单实例，保留模块内部位级阵列。

### 混合仿真尚未成功启动转换

- `Interactive.10` 的 Xcelium 日志报告 mixed-signal application license checkout failure (`NOLICN / LMF-03005`)。此前 HDL 编译、混合展开及 connect module 插入不能代替实际仿真成功。
- 改用纯 Spectre 的 `Interactive.11/.12` 在读入阶段报告实例 `I90` 的 `flash_decoder_adder` 未定义；当前 config 将该 cell 绑定到 SystemVerilog view，纯 Spectre 路径并未提供可用定义。
- 搜索范围内历史 runlog 亦有 simulation errors；功耗表达式存在 Error。没有找到可作为完整转换、噪声或 SNDR 验收的已完成波形结果。配置 `tran stop=30 us` 只是分析设置。

恢复路径可以是可用的 AMS 环境，或明确转换并验证 Flash/decoder 的纯模拟行为接口；不能把配置改为 Spectre 就视为等价成功。本轮没有修改许可证设置或覆盖原仿真配置。

### 比较锁存器的时钟缺口

当前顶层 `CLKn` 只连到 `COMP_AZ.CLKn`，没有找到活跃驱动实例；内部继续连到锁存器时钟管。与此同时，`CLK` 由 SAR 内部 3.3 V 理想源供电的 NOR 产生，直接进入 1.8 V 比较器/锁存器时钟门。保存网表与当前 OA 都支持这些连接。需要补足并验证互补相位，以及检查电平转换、器件电压限值和时序；这里不把网名存在当作时钟有效，也不在未查 PDK 限值时断言器件损坏。

### “ALL_TRANSISTOR”仍含行为器件和理想源

当前 `Flash` 是三个理想阈值的 Verilog-A 模型，输出 thermometer code，再由 SystemVerilog `flash_decoder_adder` 转成 2 位；没有 Flash offset/noise/metastability 证据。`COMP_AZ` 保留理想 relay 和行为 XOR，SAR 逻辑也有行为 inverter 与内部 3.3 V 理想电源。名字不能用作全晶体管或硅上功耗证明。

顶层的三个电源平均功率表达式不能完整覆盖内部理想源、参考和偏置供给；后续功耗对标需明确边界，分别统计正常转换、SRM、校准以及输入/参考驱动。

## 数字功能与论文的对应

| 环节 | 远程现状 | GitHub v5.1 / 缺口 |
|---|---|---|
| 非二进制冗余 | 四段电容网络；物理支路 20 路 | core raw20 和 weight20 保留该结构；最终16位必须校准重构 |
| 正常转换 | 晶体管 `SAR_Logic_transistor_woflash`；另有独立 SV controller 文本 | GitHub core 没有 normal SAR sequencer；不能直接替代完整转换控制 |
| Flash | 三比较结果→thermometer→2-bit decoder | SV controller 没有 Flash 输入；三路 thermometer 不能直接占 raw 高3位 |
| 校准 | `Digital_Process` 有 P/N 搜索和发布流 | 新 core 增加采样/状态/检查；两者都只发布6..19，且尚未接 SS+SRM-assisted 校准 |
| 参考权重 | 旧重构 RAM 初始化全0 | 需要显式播种 `W[0..5]=256<<i`，不能等待不存在的6次发布；也要防止未校准高位使用 |
| SRM | 当前模拟顶层无22次保持判决→计数→残差→重构的已接通链 | core 有计数/LUT输出；存在已复现的 arm/超时归属问题，见 [RTL复核](rtl_principle_review_20261002.md) |
| 重构 | 旧 `sar_reconstruction` 做 signed 权重加减、除2、Q8舍入及16位饱和 | 无 residue 输入；需对齐极性/LSB坐标并在最终舍入前减残差，保留 raw/residue 样本归属 |
| 工艺 | 模拟库绑定 TSMC18，1.8/3.3 V 多电压域 | 历史后端为 SMIC18；可建立逻辑接口，但单芯片物理实现需选定工艺并重新实现数字块 |

旧 SV `sar_adc_controller` 每位两拍，20位再加状态开销；以100 MHz使用时 start→result 约42拍/420 ns，不能证明5 MS/s。它在 DONE 后返回 IDLE 时清除 SAR/CDAC寄存值，也没有固定 CDAC 的 SRM 窗口。**这只是该文本模型的行为，不是当前异步晶体管 SAR 的实测速度。**

旧 `Digital_Process` 是单级比较器采样，缺少新版本的半 LSB 中心修正和 overrange；DONE 不能直接重新校准。换入新版本必须重新验证非二进制权重数值，不能把一次替换当作更高精度证明。参考权重问题是两个模块直接连接时的确定性风险，当前 OA 顶层尚未实例化该组合。

## 已统一的引脚与仍需电气验证的部分

交付 [引脚规范及使用说明](../integration/README.md)、[20路电容权重映射](../integration/analog_weight_map.csv)、[模拟边界表](../integration/analog_boundary.csv)。数字核心现有 31 组 / 176 位保持稳定；附 source CDL 和提取 SPICE 的逐位顺序及重排适配器，避免把 source 端口顺序套到提取网表。

1. **电容索引：** `W[i] / C_i` 对应物理支路 `j=i+1`；P 顶板侧底板为 `BITD<j>`，N 顶板侧为 `BITU<j>`。这来自实际网络连接，不能从 U/D 字母推测 P/N。
2. **阶段索引：** driver 支路 `j` 使用 `SET<20-j>`。正常逻辑输出 `BITP/N<20:1>` 覆盖20个物理支路；`BITP/N<0>` 在 `SET<20>` 采样且没有 CDAC 支路，需保留其最终判决/终止角色待验证，不能机械裁剪21位总线。
3. **Flash：** `D<3:1>` 分别 high/mid/low，对应 decoder `thermo<2:0>`；decoder的2位再进入高位阶段。raw 选 `BITP` 还是 `BITN`、必要反相以及 residue 正号必须做同一坐标的已知输入测试。
4. **控制与电气分离：** `dac_p_force/n_force` 是抽象校准码，实际 driver 还需要 SET、RST、安全态和电平转换；单个 force bit 不能直连模拟开关栅极。校准与正常转换只允许一个控制 owner。
5. **时钟/复位：** `rst_n` 是数字全局低有效复位；远程 `RST/RST1/RSTT/CLK0/CLK00` 是不同相位脉冲。它们不是一组可互换名字；`READYN` 也不能直接当作同步 `dec_clk` / valid / ready 三者。
6. **物理供电：** core source CDL 用 `.GLOBAL VDD/VSS`，提取 SP 有178个formal含供电；不能仅靠改pin名把1.8V逻辑接到3.3V栅控。现存LEF有109个标准单元macro，没有 core macro，PG/LVS也尚未闭合。

统一的是可追踪的命名、索引、端口顺序和边界契约。模拟侧电压阈值、极性、稳定时间、phase controller、校准 MUX、SRM hold/arm/abort 及最终重构仍有明确未完成项；原 OA 原理图和历史签核证据未被重命名覆盖。

### 电容和电路估算的适用范围

顶板直连的五个理想电容为 `(8+8+16+32+64)cf=128cf`；它通过 `12cf` 桥接到其余分段。当所有底板小信号钳位、内部节点浮置、忽略其余比较器/布线/开关负载时，顶板电容满足 `128cf ≤ Ctop ≤ 140cf`，代入保存配置得到 **5.12–5.60 pF/侧**。若进一步假设所有支路完全符合Fig.6理想比例，电容矩阵解为约5.47893pF。后一个数字是条件模型，不是当前MOM实际模型仿真值，也不是输入端等效电容。

保存网表中10个MOM调用由几何参数决定，没有把GUI `c` 字段作为调用参数；因此不能根据该字段直接宣称某支路实际为7.41408fF，或仅凭两侧字段字符串不同认定真实失配。反过来，相同几何的单元也没有证据能自动实现原图所需不同Cu倍数。需要按PDK端子含义、几何和底板寄生生成电容矩阵，并检查低6位参考比值与20个有效权重。`analog_weight_map.csv` 的比例列特意标为 **paper_relative_cap_units**，不冒充已测权重。

主Cs以外还有自举电容及内部MIM。把所有声明电容相加只可做库存，不能直接代入kT/C、输入驱动能量或论文采样负载；正确方法是按采样、噪声转移、AZ、bit-cycling与SRM各相位建立网络，再测输入导纳、扰动和噪声传递。
