## 2. ★ 源侧完全对上，残差只能来自"上下文"

用 kit CDL 按层次递归展开，乘上每个 master 的实际放置数：

```
Σ(放置数 × CDL 器件数)  = 50026
Calibre 的 SOURCE 计数  = 50026     差 0   ✓
Calibre 的 LAYOUT 计数  = 50686     比 CDL 应有多 +660
```

且 **CDL 里没有任何 `M=` 多重性参数**（0 处）——"指状/多重性口径"这条解释也不成立。

至此，四条可能路径**全部被实测排除**：

| 候选 | 检验 | 结果 |
|---|---|---|
| 库数据自洽性 | 109 个 master 单独跑 LVS | **109/109 CORRECT**（第 5 轮） |
| 单元数多了/少了 | 展平网表 vs 版图放置 | **3626/3626，零差**（第 5 轮） |
| 帧/141 文本声明 | 去掉 4 处 `PORT LAYER TEXT 141` 重跑 | **数字完全相同** |
| 几何来源 | kit 内层 vs 合并内层逐层比对 | **IDENTICAL**（7/7） |
| 多重性口径 | CDL 中 `M=` 检索 | **0 处** |
| 源网表缺器件 | Σ(CDL 展开) vs Calibre 源计数 | **差 0** |

**⇒ 唯一剩下的解释：版图提取器在"单元内容之外"多提取了 +660 个物理器件，
即由放置上下文（相邻单元 abutment / M1 轨 / M2 条带 / 井连接）生成。**
变换后仍残留 **+50**（MN +14 / MP +21）与 **35 个"版图有、源没有"的单管**，
后者经**降层验证坐在真实扩散(AA)+多晶(GT)上**：


## 4. 本轮装置坑

1. **`LVS REPORT` 的 sed 替换误伤 `LVS REPORT OPTION` 行** → `Error SPC1 ...
   superfluous specification statement`。锚点要写成 `^LVS REPORT "..."`。
2. **SREF 的 XY 只有一个放置原点**，不是 bbox；跨层定位必须用「父局部坐标 − 子原点」，
   且要**先下钻子单元再回退自身**（否则在有外框的帧单元上就停住）。
   我为此改了三次才让探测走通，**期间两次"全部落在实例外"的结论都是工具错，不是事实**。
3. `fc_shell` 继续遵守 `-f x.tcl < /dev/null`（否则出错后它会吃掉管道里的 bash）。
