## 1. 先更正：**"顶层 cell 没有几何"是我的解析器错，不是版图错**

我第一版 GDS 解析器把记录码写错了：

| 我写的 | 正确的 | 后果 |
|---|---|---|
| `0x03 → BOUNDARY` | **0x03 = UNITS** | 多边形一个都数不到 |
| `0x21 → XY` | **0x10 = XY** | 面积算不出 |
| `0x08 → ENDEL` | **0x08 = BOUNDARY** | ← **这就是"顶层无几何"的真因** |
| `0x04 → TEXT` | 0x04 = ENDLIB | — |

改正为 `0x08 = BOUNDARY / 0x09 = PATH / 0x0C = TEXT / 0x10 = XY / 0x11 = ENDEL` 后重跑。

**⇒ 版图一直是正常的；错的是我的解码表。上一轮那条"异常"撤回。**

## 3. `3735 vs 3626` 这条仍在，但性质已明确

```
顶层 SREF 总数        34465
其中 $$via* 阵列      30730
余下（"real cell"）    3735      ← 网表/LVS 是 3626 个单元
distinct masters      224       = 109 库单元包装 + 109 内部哈希名 + 6 个 $$via
```

**⇒ 顶层多出 109 个 SREF、多出 109 种 master。**
109 恰好等于库单元种类数，形态上像是**包装层与内层各被引用了一次**（kit 的两级结构）。
**这条仍未解释清楚，本轮不猜。**
