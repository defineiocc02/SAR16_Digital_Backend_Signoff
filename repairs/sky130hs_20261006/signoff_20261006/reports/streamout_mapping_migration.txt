The supplied SKY130HS .lyt uses obsolete KLayout LEF/DEF XML options (routing-suffix etc), which KLayout 0.30 silently ignores. Initial audit detected routed layers incorrectly assigned numeric 1-11. This streamout adapter uses the modern option names from the same pinned ORFS SKY130HD .lyt, while preserving the original HS GDS layer map and exact HS LEF/GDS; it does not substitute HD cells or alter the design. Final audit must reject unexpected manufacturing geometry layers.
