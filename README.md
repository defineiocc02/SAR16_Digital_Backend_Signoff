## 方法学（这份工作最值得看的部分）

期间**撤回或更正了自己的 12 处结论**，其中 4 条曾被当成"交付方缺陷"写进报告：

| 被撤回的"发现" | 真实原因 |
|---|---|
| 交付网表没有定义复位 | 把一条**反相器链**当成了未写值的 tie 根 |
| 主状态机不前进 | 在**错误的复位假设**下取数 |
| GDS 顶层 cell 没有任何几何 | 自己的 GDS **记录码表写错**（`0x08` 才是 BOUNDARY） |
| GDS 放置 3 735 vs 网表 3 626 | 把**全文件** SNAME 计数当成了顶层放置 |
| 顶层计数读数为 0 | 测试台生成器**丢掉端口位宽**，5 位总线只读到 LSB |
| "GT poly 1 个图形" | 在 `BOUNDARY` 记录上计数时该元素的 `LAYER` 尚未读到，用了上一个元素的层号 |

版图渲染部分另外修掉 4 个会让图"看着对但全是错的"缺陷：层次只展开一级（图里没有晶体管）、
`ENDEL` 未解析导致 `ANGLE` 状态泄漏到几乎所有实例、层号靠猜（实为 14=NW、50=CT）、
绘图字体缺中文字形。

结论固定成三条规矩：① 每条结论必须有对照；② **检查必须先证明自己跑过**；
③ 不引用自己没有实测过的计数。逐条记在 `docs/_过程记录/`。
