HFSNET_124  -> CLKINVX3(HFSINV_6951_589)  pin A = HFSNET_124

**⇒ 链路是：**

```

```

**`HFSNET_124` 由 `rst_n` 驱动，不是"无驱动的常量根"。**
两次反相后 `HFSNET_119 = rst_n` —— **复位是通到两个子模块的。**

按上面这条链，`rst_n=1 → HFSNET_124=0 → HFSNET_119=1 → rstn_srm=1`，**应与实测相反**。

**⇒ 两者必有一个是错的，本轮无法裁定。** 可能是：

  **这正是第 5 轮踩过的坑：同名不同层的网**。**本轮没有打印它的模块归属，所以不下结论。**

或读数有误）——**具体原因待用一次最简仿真重测，不再靠推理。**
