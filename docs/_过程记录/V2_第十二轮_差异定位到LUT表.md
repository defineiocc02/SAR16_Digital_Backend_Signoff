# 独立核查 V2 第十二轮：**差异定位到 LUT 表本身**（不是 RTL 用错表）

**方法**：读 `rtl/srm_residue_lut.sv` 的**实际表体与寻址逻辑**（上一轮我只读了参数与注释）。

---

## 1. RTL 侧：**它完全按表取值，没有错**

```
5'd0  : tbl_q8 = -16'sd258;
5'd1  : tbl_q8 = -16'sd194;
5'd2  : tbl_q8 = -16'sd158;
5'd3  : tbl_q8 = -16'sd131;
5'd4  : tbl_q8 = -16'sd110;
5'd5  : tbl_q8 =  -16'sd91;
5'd6  : tbl_q8 =  -16'sd74;
5'd7  : tbl_q8 =  -16'sd58;      <-- 本次测量落在这一项
5'd8  : tbl_q8 =  -16'sd43;
5'd9  : tbl_q8 =  -16'sd28;
5'd10 : tbl_q8 =  -16'sd14;
5'd11 : tbl_q8 =   16'sd0;
```

寻址（`HALF_TABLE` 分支）：

```
negate   = (cnt > MID)                       // MID = 11
selected = tbl_q8(negate ? (22 - cnt) : cnt)
v_res    = OUT_WIDTH'((negate ? -selected : selected) >>> SHIFT)   // SHIFT = 0
```

**本次 `cnt = ones_count = 7 ≤ 11` ⇒ `v_res = tbl_q8(7) = −58`。实测就是 `−58`。**
**⇒ RTL 对表的使用是逐位正确的。上一轮把它记成"residue 不一致"是把矛头指错了地方——不一致在表里，不在用法里。**

## 2. 表本身：与论文式**系统性偏离**

以 `SIGMA_Q8=128`（0.5 LSB）、`N=22` 代入论文式 `v_res = sigma · Φ⁻¹(cnt/N)`，
再乘 256 换成 Q8，与表项逐项比（Φ⁻¹ 用近似值，仅看趋势）：

| `cnt` | 论文式 ×256（约） | 表项 | 表项偏离论文式 |
|---|---|---|---|
| 11 | 0 | 0 | **0** |
| 10 | −14.6 | −14 | −0.6 |
| 9 | −29.4 | −28 | −1.4 |
| 8 | −44.7 | −43 | −1.7 |
| **7** | **−60.5** | **−58** | **−2.5** |
| 6 | −77.4 | −74 | −3.4 |
| 5 | −95.7 | −91 | −4.7 |
| 4 | −116.4 | −110 | −6.4 |
| 3 | −140.3 | −131 | −9.3 |
| 2 | −170.9 | −158 | −12.9 |
| 1 | −216.3 | −194 | −22.3 |
| 0 | −∞ | −258（饱和） | — |

**三个稳健特征**（不依赖我 Φ⁻¹ 近似的小误差）：

1. **`cnt = 11`（P = 0.5）处精确为 0** —— 对称点没错；
2. **偏离随 `cnt` 远离 11 而单调增大**（0 → −22）；
3. **表项一律"偏小"（更靠近 0）**，即表的等效 sigma 比 0.5 LSB 小。

**⇒ 不是随机误差，是系统性的**：要么生成表的 sigma 不是 0.5 LSB，
要么用的是另一个 P 定义（例如带连续性修正 `(cnt+0.5)/N` 之类）。

**注意**：单纯换 sigma **解释不了**——因为偏离量与 cnt 有关，
比值 `表项/论文式` 从 cnt=10 的 0.96 变到 cnt=1 的 0.90，**不是常数**。

## 3. 因此结论要写成这样

| 层 | 结论 |
|---|---|
| RTL 用表 | **逐位正确** ✅（`cnt=7 → −58`，实测 −58） |
| 计数 | **精确吻合** ✅ |
| **LUT 表内容 vs 论文式 (4.13)** | **系统性偏离，最大 22 Q8（≈0.086 LSB）@ cnt=1；未解释** ❌ |
| 交付网表层面 | **被复位/状态机缺陷阻断** ❌ |

**⇒ 上一轮我写的"`residue_o` 与论文式计算不一致"是正确的观察，但归因错误：
不是估计器实现不对，而是查表的内容与论文式不同。**

## 4. 下一轮（明确动作）
