## 1. 本轮做的事与结果

上轮把残差逼到"**提取器在单元内容之外由放置上下文生成器件**"，并给了两个支撑观察：
① 被标记的 35 个管子"降层验证坐在真实 AA+GT 上、归属 INVXL/NOR2XL/DFFSX1…"；
② 被标记点上"有 2–3 个相邻实例的扩散同时覆盖"。

本轮为了确证 ②，**先做了对照**（这是唯一正确的顺序）：随机取 300 个已放置单元的中心，
用同一套代码数"有多少个实例的 AA/GT 覆盖该点"。

```
CONTROL（300 个随机单元中心）
   AA 覆盖该点的实例数 : 1→79, 2→154, 3→56, 4→10, 5→1
   GT 覆盖该点的实例数 : 1→96, 2→153, 3→45, 4→6

被标记的 35 个点
   AA : 0→20, 1→11, 2→3, 3→1
   GT : 0→17, 1→13, 2→5
```

**普通单元中心在几何上竟有 2–5 个实例的扩散"覆盖"同一点 —— 这不可能。**
（真实标准单元行里，相邻单元的扩散不会互相覆盖。）

**⇒ 观察 ② 是伪影，不是机制。** 我据此做了两次修正尝试（补上帧内 SREF 原点、
去掉误减的 bbox 原点），**对照直方图逐位不变** —— 因为整体平移不改变重叠关系，
所以真正的错误在我的**顶层放置模型**里，而不是那个偏移量。我**没有查出**它错在哪。

## 4. 若下一轮继续追这条线，须先做的事

**先修好放置模型，并用对照证明它是对的** —— 判据：

修模型的入手点（按可疑度）：
1. 顶层 SREF 是否带 `MAG`/`STRANS`/`ANGLE`（我只读了 ANGLE，未读 MAG）；
2. 帧外框 (0,0,13200,50400) 与真实几何 bbox (−4300,−4000,17500,55800) 的关系 ——

3. 真实单元 bbox 含共享电源轨（高 5.98 µm > 行高 5.04 µm），这会污染"单元中心"的定义。
